# Juragan Desa — v2 Plan

> Builds on the v1 baseline docs: [v1/GDD.md](../v1/GDD.md) and [v1/TECH.md](../v1/TECH.md). Written 2026-11-10 from the designer's v2 answers.
> The v1 docs are frozen. Where this plan and they disagree, this plan wins; v2 design and tech docs are written in this folder as each milestone is built.

## 1. What v2 is

| Topic | Decision |
|---|---|
| Goal | Real players, revenue. Indonesia is the subject; the game must be understandable to global players. |
| Identity | A farming game with sharp satire on top. Social suspicion is the secondary big feature. |
| Team | Solo designer + Claude. No budget. |
| Name | **Juragan Desa** (final). |
| v1 | Never played by anyone. It is the code baseline, not a release. The unfinished "week 6" work is folded into v2. |
| Headline of v2 | (1) It looks and sounds like a real game. (2) Farming has depth: rarity, seasons, many crops. (3) Politics and story: Kepala Desa. |
| Biggest complaint to fix | "Too simple, no beautiful hooks, pale world, messy UI." |
| Scope rule | Anything that bloats v2 moves to v3 or the backlog (§9). |

### The scope problem, stated plainly

The answers add up to roughly 30 systems. Built as one release that is several months of side-project
time with no player feedback along the way, which is the worst case for a revenue goal. So v2 is
split into **four releases**. The game goes public after the first one.

| Release | Name | Theme | Public? |
|---|---|---|---|
| **v2.0** | *Desa yang Hidup* | Presentation, farming depth, pinjol, retention basics, real monetization | **Launch** |
| **v2.1** | *Pesta Demokrasi* | Story, Kepala Desa, dana desa, village projects, two hidden cheats | Update |
| **v2.2** | *Tetangga* | Trading, stealing and security, hush money, housing | Update |
| **v2.3** | *Ternak & Musim* | Livestock, empang, processing, seasonal events, seed crates | Update |

"This month" is realistic for v2.0's foundation and farming milestones (M0–M2 below). A launchable
v2.0 depends mostly on how fast the map, models and audio get made in Studio, which is the
designer's side. These are estimates, not measurements.

### Who does what

| Designer (in Studio and art tools) | Claude (in this repo) |
|---|---|
| Builds the map, lighting and terrain | All Luau: services, client, UI code |
| Provides 3D models, icons, audio | Config tables, strings (ID + EN), tests, docs |

## 2. Signature hooks

The answer to "lack of beautiful hooks". Each release needs at least one moment players clip and share.

| Hook | Release | Why it lands |
|---|---|---|
| **Rarity reveal** on harvest (Biasa → Sultan), with a full-screen sting for the top tiers | v2.0 | The core dopamine loop of the genre |
| **Sinetron raid cutscene**: staged camera, triple zoom, animated police, "BREAKING NEWS" lower third | v2.0 | Already the game's best idea; v1 only has an overlay |
| **Real-world seasons**: it rains in the game when it is rainy season in Indonesia | v2.0 | A reason to come back, and a talking point |
| **Pinjol debt collector**: spams your phone, then stands at your plot shaming you to the server | v2.0 | Sharp, instantly recognisable to Indonesian players |
| **Serangan fajar** and the election count | v2.1 | Server-wide drama every 20 minutes |
| **Proyek mangkrak**: a half-built monument that stays in the village when the Kades embezzles the funds | v2.1 | Satire the whole server can see |
| **Viral ticker**: cross-server news of raids, impeachments and Sultan harvests | v2.1 | Makes the game feel populated |
| **Maling**: catching a neighbour on your CCTV | v2.2 | Feeds the report loop with real grievances |

## 3. v2.0 — *Desa yang Hidup* (launch)

### 3.1 Presentation

**World.** One map. Dense hubs, open space between them: Pasar, Balai Desa, Pos Polisi + Pos Ronda,
warung, Pak RT's house, the sawah ring of plots, a river with a bamboo bridge, a hill with the
future sawit concession, a back alley for the Tengkulak Gelap.

- The village stops being generated by code. The designer builds it in Studio; code finds things by
  **CollectionService tags and attributes** (`PasarPrompt`, `PlotAnchor` with `Index`, `NpcSpawn`
  with `Npc`, `WeatherZone`, and so on). `World/Village.luau` shrinks to "find tagged anchors and attach behaviour".
- The place file becomes the source of truth for Workspace and Lighting. Rojo keeps syncing only scripts.
- Lighting fix for the "pale" look: Future lighting, an `Atmosphere`, colour correction, warm
  late-afternoon sun, real Terrain for sawah water and the river. Each season swaps a lighting preset (§3.3).
- Characters stay Roblox avatars and R15 rigs. NPCs keep the caricature proportions.

**UI redesign.** The goal is that it does not look generated. Direction to approve:
Indonesian vernacular print, not generic rounded cards.

| Surface | Visual reference |
|---|---|
| Shop, pasar, prices | Hand-painted warung signage and *spanduk* lettering |
| Raid, fines, surat panggilan, permits | Government letter: kop surat, stamp, signature, form numbers |
| Phone | A chat-app and e-wallet parody (pinjol app, family-group forwards) |
| Receipts, sales | Thermal-paper *struk* |
| Quests | A wall calendar from a building-supply store |

Rules: image icons instead of emoji, one type scale, one spacing scale, a fixed palette taken from
the map, every screen designed at phone size first. **Process:** Claude produces static mockups of
HUD, shop, phone and raid screen; the designer approves or redirects; only then is UI code written.

**Raid cutscene.** Camera is scripted on the client: establishing shot, three zooms, police
walk-in, a letter slapped on screen with the choices. Skippable after the first viewing.

**Audio.** Wire a sound registry (`Config/Audio.luau`, IDs can be 0) for music per area, weather
ambience, UI, harvest rarity stings and the raid sting.

> ⚠️ **Audio licensing.** "No license" is a launch risk: Roblox removes unlicensed audio and can
> act against the experience, and the goal is revenue. Use Roblox's licensed catalogue, original
> recordings, or generated music whose terms allow commercial use. Do not upload commercial dangdut tracks.

**Onboarding.** A short guided first harvest (plant, harvest, sell, buy a seed) led by an NPC.
It never mentions cheating. Cheats are discovered (§4.4).

### 3.2 Crops and rarity

Twelve crops in three families. Values are starting points for the balance sheet, not final.

| Family | Crops | Behaviour |
|---|---|---|
| **Palawija** (fast) | Padi, Jagung, Singkong, Cabai, Bawang Merah | Plant once, harvest once. 1–6 min. |
| **Kebun** (slow, valuable) | Kopi, Kakao, Tembakau, Cengkeh, Durian | 10–30 min first harvest, then re-harvest several times. |
| **Perkebunan** (political) | Tebu, **Sawit** | Needs a permit from the Balai Desa. Sawit needs the hill concession, takes hours, pays the most, and is the hook for v2.1's story. |

**Rarity** is rolled by the server on harvest.

| Tier | Chance | Price × |
|---|---|---|
| Biasa | 70% | 1 |
| Bagus | 20% | 1.5 |
| Super | 7.5% | 3 |
| Langka | 2% | 8 |
| **Sultan** | 0.5% | 25 |

- Minigame quality no longer multiplies price directly; it nudges the roll (a perfect plant and
  harvest roughly doubles the chance of Super and above). Auto still works, at base odds.
- **Sifat** (traits) stack on top and come from conditions, not luck alone: *Basah* (harvested in
  rain), *Kering* (El Niño), *Organik* (never fertilised), *Oplosan* (hot, as today),
  *Bersertifikat* (a stamp bought at the Balai Desa; whether it was earned is another matter).
- An **Almanak** records every crop × tier × trait found. Completing pages gives cosmetics.

### 3.3 Seasons and weather

Kept deliberately simple: one global state, read by every server.

```
Musim     = hujan | kemarau | pancaroba
Anomali   = none | elNino | laNina
Cuaca     = cerah | hujan | badai | kabut      (rolled per server from Musim + Anomali)
```

- **Source, in priority order:** admin override → live value → calendar fallback
  (roughly Nov–Mar hujan, May–Sep kemarau, the rest pancaroba).
- **Recommendation:** ship v2.0 with calendar + admin override. El Niño and La Niña are not in any
  weather API; they are monthly climate bulletins, so a human sets that flag. A real weather API
  hook goes behind the same interface later (`HttpService`, a keyless public weather service, one
  call per server per hour, cached in MemoryStore). It adds a failure mode and little the calendar doesn't give.
- **Effects** (one table in `Config/Seasons.luau`): growth speed per crop family, which seeds the
  shop stocks, trait chances, river level (visual), and risk events: *banjir* in hujan can drown
  unprotected palawija, *hama* in pancaroba, *gagal panen* odds in El Niño.

### 3.4 Shop, tools, storage, market

- **Toko Bibit with rotating stock.** Restocks every few minutes with limited quantities per
  player. What appears depends on the season; rare seeds appear rarely. This replaces the unlimited seed menu.
- **Tools** (bought with cash, permanent): cangkul tiers (faster planting, better odds),
  gembor → sprinkler (growth), a hand tractor (plant a row at once), karung → gerobak (carry more).
- **Buruh tani.** Hired NPC who harvests ready crops into storage while you are online, for a wage.
  Skipped in v1, needed now that plots get bigger.
- **Gudang.** Storage separate from the sack, with capacity upgrades. It is what makes waiting for
  a better price possible, and it sets up hoarding in v2.1.
- **Supply and demand.** Per server. Each crop has a pressure value that rises when players sell
  it and decays over about ten minutes. Price = base × a multiplier between roughly 0.6 and 1.25.
  A price board at the Pasar shows arrows, not formulas. The legal price ceiling (HET) caps the
  Pasar; the Tengkulak Gelap ignores it, as today.

### 3.5 Pinjol

An app on the phone. Money in ten seconds, no questions.

- Borrow up to a limit set by rank and Nama Baik. A fee is added immediately; interest accrues on
  play time and, more slowly, offline, with a hard cap at 3× the principal.
- **Escalation when overdue:** phone spam → the debt collector NPC stands at your plot shouting →
  he messages "your contacts" (a server-wide shaming line and a Nama Baik hit) → he seizes
  harvest from your gudang until the debt is covered.
- **Exploit guards:** debt is saved; while in debt you cannot gift or trade cash (v2.2); one loan at a time; no borrowing during a raid.
- Design purpose: an early-game accelerator, a strong money sink, and a comedy scene.

### 3.6 Retention and status

- **Tugas harian:** three daily tasks from a pool, plus a seven-day login calendar.
- **Leaderboards:** per-server board at the Balai Desa; global boards (richest, most raided, most
  Sultan harvests) through `OrderedDataStore`.
- **Roblox badges** for first raid, first Sultan, first loan repaid.
- **Nama Baik gets its first real effects:** pinjol limit and interest, Pasar price ±5%.

### 3.7 Monetization for launch

Direction: cosmetics first. Shortcuts exist but never buy immunity or exclusive power.

| Type | Items |
|---|---|
| Passes | Ordal, Extra Plot, VIP Warung (existing), **Gudang Besar** (storage), **Auto-Panen** (buruh without wage) |
| Products | Amplop Premium, Jaminan Kilat, Karung Bibit (existing), **Restock Toko** (refresh the seed shop now), **Rupiah packs** |
| Cosmetics | Outfits, hats, plot themes, raid entrance stings, harvest effects, phone skins |

Guardrails stay as in v1 GDD §9: nothing blocks a raid, nothing clears a VIRAL case, no paid randomness in v2.0.
Real IDs and prices are set during M4. Seed crates wait for v2.3.

### 3.8 Launch checklist additions

Everything in v1 TECH.md §11, plus: maturity questionnaire answered, icon and three thumbnails, a
30-second raid clip for social, a Roblox group, analytics events for the new systems, and a
five-person playtest on real phones before the place goes public.

## 4. v2.1 — *Pesta Demokrasi*

### 4.1 Story

Five short chapters (*Babak*) delivered through NPC quests and gated by rank. They give the
farming a narrative spine and introduce each system: the debt, the first raid, the sawit permit,
the candidacy, the office. Written ID-first with EN alongside; EN lines explain the reference
instead of translating word for word, so global players get the joke.

### 4.2 Kepala Desa

v1 GDD §7.3 as designed, with these additions:

- **Dana Desa.** Sales tax flows into a visible village fund.
- **Proyek Desa (village-wide goals).** The Kades picks a project: irrigation (growth bonus),
  paved road (faster movement), pasar roof (better prices), pos kamling (fewer thefts in v2.2).
  Players contribute crops and labour; the fund pays the rest. Finished projects buff the whole server.
- **Korupsi.** The Kades can quietly divert the fund. Big payout, heavy Sus, and the project
  stalls as a visible *proyek mangkrak*. Other players can find the discrepancy on the Balai Desa
  notice board and report it. A raided Kades is impeached.
- **Serangan fajar** for buying votes, as designed.
- **Nama Baik** gates candidacy and weights NPC votes.

### 4.3 Viral ticker

A cross-server news strip through `MessagingService`: VIRAL raids, impeachments, Sultan harvests.
Throttled and built from templates only; player names appear, free text never does.

### 4.4 Hidden cheats

The Curang tab in the phone is removed. Cheats are no longer a menu.

- **Mbah Dukun-style informant** (final name to choose): a hidden NPC who moves location and sells
  hints, not instructions. This is the only place the game admits cheating exists.
- Rumours at the warung hint at conditions. Each cheat has a specific trigger the player must work out.
- **Penimbunan (hoarding).** Holding a large share of one crop in the gudang while its price is
  high pushes the price higher still. Selling at the peak is the payoff. A surprise *sidak
  gudang* inspection can find it. The thresholds are not shown anywhere.
- **Pungli.** NPC officers already skim a small fee at the Pasar gate (a sink). The hidden part:
  a Kades or Juragan can discover how to put their own man on the gate and take a cut of every
  other player's sale, which victims can notice on their receipt and report.
- The three v1 cheats stay but move to the same discovery model.

## 5. v2.2 — *Tetangga*

- **Trading and gifting.** Both players online on the same server, a two-sided confirm screen,
  one atomic server transaction, a log entry for every trade. Rank Petani and above. Cash
  transfers pay a small tax and are blocked while in pinjol debt. Check Roblox's paid-item trading
  policy before anything bought with Robux becomes tradable.
- **Maling (stealing).** Take ready crops from a neighbour's plot. It is a cheat like any other:
  Sus, evidence for witnesses, the victim always gets a bukti token.
- **Security:** pagar (slows thieves), anjing (alerts you), CCTV (records bukti automatically),
  satpam NPC (wage). Bought with cash; cosmetic variants for Robux.
- **Uang tutup mulut.** When a witness records bukti, the cheater can open a negotiation: offer,
  counter-offer, accept or refuse. Accepting destroys the token, so a paid witness cannot report
  anyway; betrayal mechanics wait for v3.
- **Housing and plot decoration.** Rumah tiers, fences, vehicles, decor slots on the plot. Uses
  the designer's 3D models. This is the main cosmetic surface for revenue.
- **Multiplayer rule:** features that need a second player switch on at two or more players in
  the server. Everything else works alone. Public servers only, ten players.

## 6. v2.3 — *Ternak & Musim*

- **Livestock:** ayam, kambing, sapi. Feed from your own crops, produce on a timer, can get sick in pancaroba.
- **Empang:** a fish pond tile type (lele, nila), affected by river level.
- **Processing:** penggilingan (padi → beras), sambal, keripik singkong, kopi sangrai. Turns raw produce into higher-value goods and deepens hoarding.
- **Seasonal events**, started by an admin: Lomba 17 Agustus, Mudik, Musim Pemilu, Panen Raya.
- **Peti Bibit (paid random seeds):** odds displayed in the purchase screen, gated by
  `PolicyService` for regions where paid random items are restricted. Verify current Roblox rules before building.

## 7. Technical plan

### 7.1 Foundation changes (all in M0, before any feature)

| Change | Why |
|---|---|
| **Data schema v3** with a migration from v2 | Generic `items[itemId] = count`; produce stored as stacks keyed by crop + tier + traits; new sections for tools, gudang, debt, quests, almanak, story, plus reserved fields for housing and prestige so later releases need no migration |
| **Replicated state module** | The answer to "idk" on Q54: yes, do it. `Seed_<crop>` attributes cannot carry 12 crops × 5 tiers × traits. Keep attributes for simple scalars (Cash, Sus, Rank); send structured data (inventory, market, quests, season) through one snapshot + delta remote with a small client store |
| **Tag-driven world** | Lets the designer rebuild the map freely without touching code |
| **LiveConfig** | One DataStore document polled every 60 s and pushed with `MessagingService`: season override, anomaly flag, active events, price multipliers, feature switches. Events never start on their own; an admin starts them, as decided |
| **Admin panel** | In-game, restricted to a user-ID allowlist: start/stop events, set season, grant items for testing, inspect a player |
| **Content as config** | Crops, tiers, traits, tools, seasons, quests, loans and projects are tables in `shared/Config`. Adding a crop must not need new code |
| **UI kit rebuild** | `Theme.luau` replaced by the approved design system; every screen rebuilt on it |

### 7.2 New services

`Season/SeasonService`, `Economy/MarketService` (supply and demand), `Economy/ShopService`
(rotating stock), `Farm/RarityService`, `Farm/ToolService`, `Farm/StorageService`,
`Farm/WorkerService`, `Finance/LoanService`, `Progression/QuestService`,
`Progression/AlmanacService`, `Social/LeaderboardService`, `Live/LiveConfig`, `Live/AdminService`,
`Net/State`. Later: `Politics/ElectionService`, `Politics/VillageFundService`, `Story/StoryService`,
`Social/TradeService`, `Farm/TheftService`, `Home/HousingService`.

The v1 TECH.md ground rules do not change: the server decides everything, one owner per piece of
state, every remote validated and rate-limited.

### 7.3 Testing

- Keep the lune unit tests; every new service gets a spec, written before the service where the logic is pure (rarity rolls, market maths, loan interest, migrations).
- **Add in-Studio integration tests:** a test place mode that spawns fake players and walks the main flows (plant → harvest → sell, loan → default → seizure, cheat → report → raid).
- A **migration test** that loads saved v2 fixtures and checks the v3 result.
- Manual sheets in `docs/testing` extended per release.
- A balance sheet (`docs/balance/`) that simulates income per minute by rank, so prices are tuned against a model before players see them.

### 7.4 Milestones for v2.0

Each one ends in something playable.

| # | Milestone | Contents | Done when |
|---|---|---|---|
| **M0** | Foundation | Schema v3 + migration, state module, tag-driven world, LiveConfig, admin panel, UI mockups approved | The v1 game runs unchanged on the new foundation; tests pass |
| **M1** | Farming depth | 12 crops, families, rarity, traits, almanak, rarity reveal | A full session produces a spread of tiers and at least one "wow" harvest |
| **M2** | Living world | Seasons and weather, rotating shop, tools, gudang, buruh, supply and demand | Changing the season from the admin panel visibly changes the shop, growth and sky |
| **M3** | The new face | Studio map, lighting, UI rebuilt on the kit, raid cutscene, audio wired, onboarding | A stranger can play ten minutes on a phone without help |
| **M4** | Money and habit | Pinjol, daily tasks, login calendar, leaderboards, badges, real passes/products/prices, analytics | Test purchases grant once; a loan can go the full way to seizure |
| **M5** | Launch | Balance pass, EN review, maturity questionnaire, five-person playtest, store assets, publish | Public |

M0–M2 are almost all code, so they can move fast. M3 is gated by art.

## 8. Risks to settle before launch

1. **Roblox access in Indonesia.** The GDD cites one unverified report that under-16 accounts were
   deactivated in March 2026. For an Indonesia-first revenue game this decides the size of the
   audience. Verify it in M0. If true, global accessibility moves from "nice to have" to essential.
2. **Sharp satire versus platform rules.** Bribery, loan sharks, vote buying and embezzlement
   affect the maturity rating, and Roblox has rules on political and sensitive content. Sharp is
   fine while every target is a system and every name is fictional. Read the current policy and
   answer the questionnaire honestly before M3 locks the writing. Indonesian defamation law is one more reason to keep it fictional.
3. **Audio licensing** (§3.1).
4. **Paid random items and trading** carry region-specific policy requirements (§5, §6).
5. **Economy exploits** arrive with trading, gifting and loans. Alt accounts will try to launder
   start cash and loans. Guards are listed in §3.5 and §5; they are tested with the spam and alt scenarios before each release.
6. **Scope.** If M3 slips because art takes longer, launch with fewer crops and one hub polished rather than everything half-finished.

## 9. Not in v2

**v3**

- Deeper law (answers 22–26): alibis, fitnah, sidang, community service, new law NPCs, visible Sus
- Prestige: leaving for a bigger village (desa → kecamatan → kabupaten) with a permanent bonus. Data fields are reserved in schema v3
- Betrayal in hush-money deals
- NPC neighbours who cheat, so empty servers still have a report loop
- Private servers (single-player features only)
- More hidden cheats, including land burning with a server-wide haze

**Backlog**

- Season pass, Premium benefits, paid plot themes
- Gamepad and console support, low-end device targets
- Automated event scheduling
- Real weather API hook
- Koperasi and arisan
