# Round 2 item 8 — hub props behind LookDev opt-in

Date 2026-11-19. Branch `track/c-world-look`. Status `SEEN-IN-STUDIO`.

## Target

Warung counter, pasar stall, pos polisi desk, Pak RT table, lanterns and signs — kept within the
per-hub instance budget. All props are CANDIDATES awaiting a designer yes/no: none approved, none
shipped on by default. Colours come from the `ART.md §3` palette; no asset IDs.

## Approach

The queue allowed procedural parts with textured materials. As with items 6/7, imported meshes were
not viable (subagent transport down, place saves forbidden), so the props are **pure-data,
source-controlled Roblox primitive-part recipes** behind an off-by-default `hubprops` LookDev
candidate: durable in Rojo, reversible, no place save, no asset IDs. The shipping greybox hub
props built by `Greybox.luau` are untouched.

## What was made

- `src/shared/HubPropCandidates.luau` — pure data + `partsFor(hubKey)`, no Roblox APIs at load.
  Each of the four hub recipes (pasar/warung/polisi/pakrt) dresses its hub's anchor with hero props:
  produce crates and a hanging awning at Pasar, coffee tray/cups/teapot/stools at Warung, desk
  lamp/papers/nameplate/badge at Pos Polisi, ledger/envelopes/tea set/chairs at Pak RT. A shared
  lantern + two-post sign is added to every hub; the sign board uses that hub's own accent colour.
- `src/client/World/LookDevHubProps.luau` — the client applier. It finds each hub Model recursively
  under `workspace.World` (direct children miss), locates its anchor BasePart, and parents detail
  parts to a single `LookDevHubPropDetails` folder, CFrame-relative to the anchor so they follow the
  hub's yaw. On disable it destroys every created instance. Enum shape/material lookups are
  best-effort (see Studio note below).
- `LookDev.luau` gains a seventh pure-data `hubprops` candidate (`idsSource` pointer, `hubCount = 4`,
  no numeric IDs), booted behind `pcall` in `Main.client.luau`. The gallery render is generated from
  the same `partsFor()` via a Lune dump, so it cannot drift.
