== Harness defect found and fixed (no check weakened) ==
First Studio run emitted GRADE_SAFE FAIL 0/3 with all three variants reading IDENTICAL baseline values
(Atmosphere Density 0.05, Haze 0.2, Bloom Threshold 1.8 — outside the variant values). Cause: the
grade appliers register with LookDev at MODULE LOAD, and the saved place's boot script predates them;
the runtime-injected applier was never required, so LookDev.enable(id) was a silent no-op with no
applier registered. Fix: review_check_r8.luau's grade block now explicitly
`require(game.ServerScriptService.Server.World.LookDevGradeR8)` (pcall-guarded, FAIL if unreadable),
and grade_r8_spec.luau locks that source guard. Re-run produced the real per-variant readings and
PASS lines above. The safe ranges, targets and restore assertions were NOT weakened — the fix makes
the check able to observe the candidates at all where it previously compared unchanged defaults.
