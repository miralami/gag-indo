== Defect found and fixed by rescaling (not by weakening the check) ==
Initial stable anchored bbox found ONE failure: bawang bibit = 0.412 studs (< 0.5 floor).
Root cause: bawang's archetype stem size[2] was 0.8; bibit stemHeight = 0.8 x 0.34 = 0.272, so the
live bbox was ~0.1 (soil) + 0.272 + ~0.04 (leaf) = 0.412. FIX in src/shared/CropModelCandidates.luau:
archetypes.bawang.stem.size[2] 0.8 -> 1.4. That lifts bibit to 0.615 studs, keeps all three stages
within 0.5..6, and keeps both growth gaps >= 15%. No other crop needed a rescale; no check value
was touched. tests/specs/crop_growth_audit_spec.luau locks stem.size[2] = 1.4 so it cannot regress.
