== Root cause ==

call makeFolder(). The old makeFolder() set a single `createdFolder = folder` reference, so the second
call overwrote the first: `createdFolder` held only the paths folder (B). clearCreated()/restore()
destroyed only B; the covers folder (A, 1 Folder + 41 cover Parts, 4 within 100 studs) survived every
enable/disable cycle. +42 descendants per cycle, exactly matching the pre-fix delta. Item 97 had
already observed the same +42 inst/+41 parts/+4 near100 residue (CHECK_097.txt:29-31, PERF_R9.md).

Replace the single `createdFolder: Folder?` reference with a `createdFolders: { Folder } = {}` list.
makeFolder() appends every folder it creates (`createdFolders[#createdFolders + 1] = folder`);
clearCreated() destroys ALL tracked folders then resets the list. Saved prior Visible/CanCollide
