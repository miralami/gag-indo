== Culprit and fix ==
Culprit: `FacadeRidgeCap` in `src/shared/ModelMapFacadesR8.luau`. Its old size was
`{ width * 0.8, 0.6, 1.2 }` with width = the hub model width (32–64), so the gold bar was 25.6–51.2
studs long — the "long yellow diagonal pole" in the Pak RT shot (pakrt: 38.4 studs). It also lay
across pakrt's Z-running ridge. Fix: cap length fixed at 10 studs for every hub, and a `ridgeAlongZ`
flag turns pakrt's cap along local Z. Additionally `FacadeEave_L` on pakrt was 0.3 studs past
hub-bbox+3; `eaveX` was reduced from `gauge.w/2 + 10` to a fixed 12 studs. All six hubs checked; no
other stray parts remain.

== FACADE_STRAY method (target 0, unweakened) ==
Per hub, for every staged Part tagged `FacadePart == true`: rotation-aware world AABB must fit inside
the hub Model bbox grown 3 studs on every axis, its top must be <= ridge + 1, and no AABB side may
exceed 12 studs. AABB is computed from CFrame + Size corners because this Studio API surface does
not expose `GetBoundingBox` on Part; hub Model bbox is the union of its descendant BaseParts. A
missing folder, gauge, hub Model or unreadable bbox is counted as an offender, never a vacuous pass.
First two attempts correctly FAILED (60 unreadable part bboxes, then 6 unreadable hub bboxes); the
helper was fixed, not the target. Final detail: offenders = [].
