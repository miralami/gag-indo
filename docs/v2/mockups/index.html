Juragan Desa — v2 UI direction

Static proposal for decision D1 in docs/v2/DECISIONS.md. Nothing here is wired into the game: the v1 Theme.luau stays in place until the direction is approved or redirected. Feedback is per screen, not per pixel.

Direction: Indonesian vernacular print — hand-painted warung signage, government letters with kop surat and stamps, thermal struk, and a chat-app parody for the phone. Warm paper palette, one type scale, one spacing scale.

How to review: open this file in a browser (no build step, no assets). Reply per numbered screen: approve, or redirect with one sentence. D1 in docs/v2/DECISIONS.md stays open until then; the v1 Theme keeps the game running.

Constraints this proposal respects: 320 px width first, image icons instead of emoji, one type scale, one spacing scale, and a palette taken from the map (paper, ink, red signage, leaf green, turmeric, night blue).
