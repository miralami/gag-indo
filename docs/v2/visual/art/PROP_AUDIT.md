# Prop audit — round 3 item 3 (V-D3)

**Decision V-D3 (`docs/v2/plan/DECISIONS.md`): replace all ten low-poly props with real 3D models from the D15 asset ladder.** This table is the audit the decision asked for: the current representation, its LookDev coverage, the verdict, and one real ladder candidate (plus a fallback) per slot. No agent has ingested any of these candidates, and **no asset ID is invented here** — every source below is a verified page, and an ID is only recorded in `ASSET_MANIFEST.md` after a real Open Cloud upload.

## Current state

All ten slots are Quaternius low-poly FBX imports from Poly Pizza's Medieval Village Pack (`https://poly.pizza/bundle/Medieval-Village-Pack-NsHhjhlrfY`, CC0), recorded in `ASSET_MANIFEST.md` §3 lines 73–82. They are flat-colour, low-triangle (188–2,659 tris) stand-ins, **not** the cartoonish-realism target of D11/D14. All ten are covered by the off-by-default `hubprops` LookDev candidate (`src/shared/LookDev.luau`), which dresses them with primitive-part detail but does not replace them; the designer verdict on `hubprops` was **no — rebuild as real 3D models, case by case** (`docs/v2/visual/CANDIDATES.md`). Current status of every slot is `UNVERIFIED`; none has an approved ID.

D15 ladder order (DECISIONS.md): **(1)** free/CC0 assets (Creator Store with scripts stripped, Poly Haven, CC0 Sketchfab); **(2)** auto-generated via Studio/Blender MCP; **(3)** designer builds; **(4)** Roblox parts/CSG. The candidate below is step (1) wherever a verified high-fidelity free model exists; otherwise a concrete step (2)/(3) fallback is named.

## Notes and hand-off

- **Licence verification**: Poly Haven's site licence is https://polyhaven.com/license ("Our assets are all licensed as CC0"); ambientCG's is https://ambientcg.com/view/license ("Creative Commons CC0 1.0 Universal License"). Sketchfab's `plaggy` pages carry the explicit `CC0 1.0 Universal` dedication in the model-information block — the strongest Sketchfab evidence here. The `gerobak` and `motor` Sketchfab pages claim CC0 in the description but show platform field `Free Standard`: **confirm in-browser before ingest** and do not record either as CC0 on faith.
- **Why not another Poly Pizza model**: the current ten are already Quaternius CC0 from the same pack; another low-poly model from that source would not satisfy the D14 fidelity aim or V-D3. The step (2)/(3) fallbacks are named exactly where no verified high-fidelity free model exists (`sumur`, `hut`).
- **Per the queue rules** (`WORK_QUEUE.md` §"Rules for every asset"): each ingested model must be a LookDev candidate, off by default, with a `CANDIDATES.md` row; source/licence/author and the **real** Open Cloud ID go into `ASSET_MANIFEST.md`; keep the per-hub instance/triangle budgets (`VISUAL_MASTER_PLAN.md` §6); and the designer (or a vision-capable observer) owns the yes/no — an agent cannot judge these renders as "good".
- This audit is a **planning document only**. No model was downloaded, uploaded, inserted, or approved; no visual verdict is claimed. Ingestion is items 4/6 and the per-model ladder work, not this item.
